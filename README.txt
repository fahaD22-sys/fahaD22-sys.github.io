GitHub Pages setup:
1. Create a public repository named YOUR_USERNAME.github.io (replace YOUR_USERNAME with your actual GitHub username).
2. Upload index.html, amalkom-logo.png, and nawar-etad-mohammed.vcf to the root of that repository.
3. Repository Settings > Pages > Build and deployment > Deploy from a branch > main > / (root) > Save.
4. After deployment, visit https://YOUR_USERNAME.github.io
5. Use that exact live URL to create the final printable QR code for your business card.
Note: This bundle does not deploy the site or contain a verified QR code yet.
